# EEA Evidence

Curated evidence repository for the Economic Espionage Act referral.

## Structure

- `EVIDENCE_INDEX.md` - master exhibit index
- `HASH_MANIFEST.md` - SHA-256 manifest for included files
- `GAPS.md` - unresolved references from the cross-reference pass
- `evidence/` - curated matched evidence organized by referral section
- `LICENSE.md` - Licensed under the Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International License (CC BY-NC-ND 4.0).

Only matched evidence from the curated manifest is included here. Medical PDFs and orphaned files were excluded.
